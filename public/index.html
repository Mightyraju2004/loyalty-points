Product Overview

CafeRewards helps café staff register members, add points on each purchase using the member's tier, and redeem free items while keeping the live balance accurate at every step.

🎯 Target Audience

Independent cafés, campus coffee shops, and local food chains that want a simple loyalty counter for regular customers.

⚡ Key Features

  • Staff login and secure dashboard
  • Tiered earn rates (Silver 1x, Gold 2x)
  • Live balance updates and instant redemption
  • Phone-number lookup, search, pagination, and sorting

🚀 Next 3 Features to Build

  1. SMS Notifications: Real-time alerts when earning points.
  2. Birthday Multipliers: Automatic bonus points on special days.
  3. Analytics Dashboard: Revenue tracking by loyalty tier.
